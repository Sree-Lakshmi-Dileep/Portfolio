PlateShare – Food Donation Platform

Hackathon Project | Tink-Her-Hack 3.0 (Thinker Hub)
Tech Stack: Vite, React.js, Firebase (Auth + Firestore), CSS

github : https://github.com/Sree-Lakshmi-Dileep/PlateShare

PlateShare is a web-based food donation platform that connects donors with those in need to reduce food wastage and promote social good. Built using Vite and React, the app features a clean UI with navigation across Home, About, Contact, Dashboard, and Food Listings pages. Firebase was integrated for secure user authentication and cloud database storage, allowing users to register, log in, and store data in Firestore. Developed as a team project during the Tink-Her-Hack 3.0 hackathon, the platform lays the groundwork for real-time food sharing and community support.
